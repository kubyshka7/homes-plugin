# Homes

Плагин для Minecraft-сервера на Paper. Игрок сохраняет точки «домов» и возвращается к ним командой
или через меню. Точки хранятся в PostgreSQL.

## Что умеет

- `/sethome [имя]` сохраняет дом там, где стоит игрок. Без имени дом называется `default`.
- `/home [имя]` телепортирует к дому через 10 секунд. Пока идёт отсчёт, вокруг игрока крутятся частицы,
  а если он получит урон, телепорт отменяется.
- `/homes` открывает меню со списком домов. Из него можно телепортироваться, перенести точку на текущее
  место, переименовать дом (новое имя пишется в чат), удалить его или добавить новый.
- `/delhome [имя]` удаляет дом.
- У каждого игрока есть лимит домов: по умолчанию 3, больше можно выдать правом `homes.limit.N`.
- Все сообщения меняются в `config.yml`.

## Команды и права

| Команда | Право | Кому доступно |
| --- | --- | --- |
| `/sethome [имя]` | `homes.sethome` | всем |
| `/home [имя]` | `homes.home` | всем |
| `/homes` | `homes.list` | всем |
| `/delhome [имя]` | `homes.delhome` | всем |
| | `homes.limit.N` | лимит в N домов вместо стандартного |

## Как устроено

- Java 21, Paper API 1.21, сборка Gradle (Kotlin DSL). Плагин Shadow упаковывает HikariCP и драйвер
  PostgreSQL внутрь jar, поэтому на сервер ничего дополнительно ставить не нужно.
- База: PostgreSQL через пул соединений HikariCP. Таблица `homes` создаётся при запуске, первичный ключ
  `(player_uuid, home_name)`. Сохранение дома делается одним запросом `INSERT ... ON CONFLICT DO UPDATE`.
- Работа с базой спрятана за интерфейсом `HomeRepository`, реализация `JdbcHomeRepository` на JDBC
  с `PreparedStatement`.
- Запросы к базе идут в асинхронных задачах, чтобы сервер не подвисал. Сообщения игроку и сам телепорт
  возвращаются в основной поток сервера.

```
com.example.homes
├── HomesPlugin.java   запуск плагина, регистрация команд и слушателей
├── command/           /sethome, /home, /homes, /delhome
├── gui/               меню домов и меню действий с домом
├── storage/           подключение к PostgreSQL и репозиторий
├── teleport/          телепорт с задержкой и его отмена
└── model/             record Home
```

## Сборка и запуск

```bash
./gradlew build
```

Готовый файл появится в `build/libs/homes-plugin-1.0-SNAPSHOT.jar`. Его нужно положить в папку `plugins`
сервера Paper 1.21+, один раз запустить сервер, затем указать данные PostgreSQL
в `plugins/HomesPlugin/config.yml` и перезапустить.
